# Smart Student Mess & SpaceFit Room Allocation System 

Managing student accommodation and mess operations involves several interconnected tasks, including room and bed allocation, meal attendance, and complaint resolution.

**Smart Student Mess & SpaceFit Room Allocation System** is a full-stack MERN application that brings these operations together on a centralized platform. It provides role-based access for students, managers, and administrators, with features for room and bed allocation, waitlist management, meal check-ins, profile management, and complaint review.

The system aims to streamline accommodation management, improve operational efficiency, and promote transparency, accountability, and a better student living experience.
